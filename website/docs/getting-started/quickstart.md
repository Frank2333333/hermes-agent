# Quickstart

| Goal | Recommendation |
|---|---|
| Use Hermes locally | Start with `hermes` |
| Configure an internal model | Run `hermes model` |
| Expose an internal API surface | Run `hermes gateway run` |

## First run

```bash
hermes
hermes model
```

## Optional API server runtime

```bash
hermes gateway run
```

This enterprise build does not include public messaging-platform setup.
