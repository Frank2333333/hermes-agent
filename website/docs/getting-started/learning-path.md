# Learning Path

1. Start with the CLI.
2. Configure an internal model endpoint with `hermes model`.
3. Learn the retained toolsets: file, terminal, web, browser, memory, delegation, and cron.
4. If needed, enable the internal API runtime with `hermes gateway run`.
5. Add approved MCP servers and enterprise policy controls.
